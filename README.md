# Age Distribution Histogram

## Project Description
This project creates a Histogram using Python's Matplotlib library to visualize the age distribution of a sample population.

## Technologies Used
- Python
- Matplotlib

## Files Included
- `task.py` – Python source code for creating the histogram.
- `age.png` – Generated histogram graph.

## How to Run
1. Install Matplotlib:
   ```bash
   pip install matplotlib
   ```
2. Run the Python file:
   ```bash
   python3 task.py
   ```

## Output
The program generates a histogram showing the age distribution of people between 18 and 30 years.

**Output File:** `Figure_1.png`

## Conclusion
This project demonstrates how to create and save a histogram using Python Matplotlib for basic data visualization.
